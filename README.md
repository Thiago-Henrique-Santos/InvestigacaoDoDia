# Investigação do Dia

Projeto web estático para uma dinâmica presencial de investigação.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos para o repositório.
3. No GitHub, vá em Settings > Pages.
4. Selecione a branch principal e a pasta `/root`.
5. Salve.

## Funcionalidades

- Autenticação por senha
- Fluxo de pistas por equipe
- Persistência local
- Interface responsiva
